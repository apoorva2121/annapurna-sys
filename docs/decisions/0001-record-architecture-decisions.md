# 0001 — Record architecture decisions

**Status:** Accepted · 2026-09-08

## Context
This project spans ~36 feature areas over months. Decisions made in week 1 get re-litigated in
week 6 by whoever (human or model) has lost the context.

## Decision
Every choice that is expensive to reverse gets a numbered file here: context, decision,
consequences. Short. Superseded ADRs are marked, not deleted.

## Consequences
Cheap to write, and it stops rediscovery. Read these before proposing an architectural change.
